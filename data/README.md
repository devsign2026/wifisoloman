## 2026-08-26 구석 세션 (조건 최상, 결론의 근거)

동아리방 반대편 구석으로 전체 장비를 이설. **역대 가장 좋은 조건**에서 측정.

|---|---|---|---|---|

| `person_corner_20260826.pcap` | 사람 1명 (앞 2.5분은 부재/입실 동작) | 419s | 37.0Hz | -43dBm |

| `deepbreath_20260826.pcap` | **의도적 깊은 호흡** 0.25Hz + 숨참기 2회 | 386s | 36.8Hz | -43dBm |

배치: `[맥북] ←1m→ [파이]`, 사람은 정중앙. ping `-i 0.02`.

`deepbreath` 프로토콜: 2초 들이쉬고 2초 내쉬기(0.25Hz=15BPM)로 가슴을 크게 움직임.
0~2분 깊은호흡 / **2:00~2:30 숨참기** / 2:30~4:30 깊은호흡 / **4:30~5:00 숨참기** / 5~7분 깊은호흡.

`inout` 프로토콜 (사용자 타이머 기준, 캡처 대비 오프셋 +61초):
0~60s 부재 / **60s 입실** / 60~90s 착석 / **90s 퇴실** / 90~150s 부재 / … 3회 반복.

## 이름 규칙

`<상태>_<YYYYMMDD>.pcap` — 상태는 `baseline_empty` / `baseline_occupied` / `breath_<BPM>bpm` 등.
**날짜를 반드시 붙일 것.** 안 붙이면 다음 세션 캡처가 기존 파일을 덮어쓰거나,
서로 다른 조건의 파일이 같은 이름을 갖게 됨.

## 읽을 때 주의

**길이와 샘플링레이트가 서로 다르므로 그대로 비교하면 안 됨.**
`csi_diagnose.py --seconds N` 으로 길이를 맞추고 볼 것.

`baseline_empty_20260825`(22초)는 **너무 짧아 잘못된 결론을 유도했음.**
이걸 근거로 "재실 여부가 호흡 대역에서 갈린다"고 판단했다가 7분 캡처로 철회.
→ 기준선은 `baseline_empty7min_20260826` 을 쓸 것.

**배치 (2026-08-26 기준):** `[맥북] ····· [사람][파이] ····· [공유기]`
측정 경로는 **맥북 → 파이** (공유기는 ping 목적지일 뿐). 배치가 바뀌면 기준선 무효.

**선명도가 4 미만이면 피크 분포를 해석하지 말 것.** 스펙트럼이 평평하다는 뜻이고,
그때 피크 위치는 잡음이 FFT 격자 어디에 앉았느냐일 뿐이다.
