## 이름 규칙

`<상태>_<YYYYMMDD>.pcap` — 상태는 `baseline_empty` / `baseline_occupied` / `breath_<BPM>bpm` 등.
**날짜를 반드시 붙일 것.** 안 붙이면 다음 세션 캡처가 기존 파일을 덮어쓰거나,
서로 다른 조건의 파일이 같은 이름을 갖게 됨.

## 읽을 때 주의

**길이와 샘플링레이트가 서로 다르므로 그대로 비교하면 안 됨.**
`csi_diagnose.py --seconds N` 으로 길이를 맞추고 볼 것.

`baseline_empty_20260825`(22초)는 **너무 짧아 잘못된 결론을 유도했음.**
이걸 근거로 "재실 여부가 호흡 대역에서 갈린다"고 판단했다가 7분 캡처로 철회.
→ 기준선은 `baseline_empty7min_20260826` 을 쓸 것.

**선명도가 4 미만이면 피크 분포를 해석하지 말 것.** 스펙트럼이 평평하다는 뜻이고,
그때 피크 위치는 잡음이 FFT 격자 어디에 앉았느냐일 뿐이다.
