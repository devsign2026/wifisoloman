# wifisoloman

**저장소:** https://github.com/devsign2026/wifisoloman (organization `devsign2026`, public)

WiFi CSI(Channel State Information)로 **사람의 호흡을 비접촉 감지**하는 실험 프로젝트.

라즈베리파이의 WiFi 칩(BCM43455c0)을 [Nexmon CSI](https://github.com/seemoo-lab/nexmon_csi)로 패치해
전파의 미세한 변화를 뽑아내고, 신호처리로 분당 호흡수(BPM)를 추정한다.
카메라나 웨어러블 없이 **전파만으로** 재실·호흡을 감지하는 것이 목표.

> ⚠️ 진행 중인 실험이며, **아직 호흡 감지가 검증되지 않았다.** 아래 「현재 상태」 참조.

---

## 원리

WiFi 전파는 송신기에서 수신기까지 직선으로만 가지 않는다. 벽·가구·사람에 반사되어
수십 갈래 경로로 들어오고, CSI는 그 합을 서브캐리어(주파수 채널) 단위로 기록한 값이다.

사람이 숨을 쉬면 가슴이 수 mm 움직이고, 그만큼 반사 경로의 길이가 변한다.
이 변화가 CSI 진폭에 **호흡 주기(0.2~0.5Hz)의 미세한 진동**으로 나타난다.
즉 WiFi를 저해상도 레이더처럼 쓰는 셈이다.

```
[공유기] ~~~전파~~~> [파이 = CSI 수신]
     └──── 사이에 사람 (호흡으로 반사 경로 변조) ────┘

[트래픽 발생기] ── ping 홍수 ──> CSI는 패킷이 날아갈 때만 추출됨
```

## 구성

| 역할 | 장비 |
|---|---|
| CSI 수신 (센서) | Raspberry Pi 4B, 커널 `5.10.92-v7l+` 고정, Nexmon CSI 패치 |
| 신호원 | 5GHz 공유기, 채널 149 / 80MHz 고정 |
| 트래픽 발생기 | 여분 노트북 — `ping -i 0.01` 로 초당 ~100패킷 |
| 분석 | Python (CSIKit, numpy, scipy) |

80MHz 대역에서 서브캐리어 **256개**, 실측 샘플링레이트 **77~127Hz**.
호흡(0.2~0.5Hz) 감지에는 충분히 빠르다.

---

## 신호처리 파이프라인

```
pcap 파싱 (CSIKit)
  → 진폭 추출 + 손상 프레임 제거
  → 유효 서브캐리어 선택 (null/가드밴드 제외)
  → 불균일 샘플링 보정 (선형보간 재샘플링)
  → 밴드패스 0.1~0.6Hz  ※ 반드시 SOS 형태
  → FFT → 피크 주파수 × 60 = BPM
```

## 현재 상태

**호흡 감지는 아직 검증되지 않았다.** 1차 실험(메트로놈 12/15/20 BPM)이 실패했고,
원인을 추적하는 과정에서 **분석 코드 자체의 버그 두 개**를 발견해 수정했다.

### 발견 1 — 밴드패스 필터가 수치적으로 붕괴해 있었음 🚨

전달함수 계수(`b, a`) 형태로 만든 Butterworth 밴드패스가 **불안정**했다.
0.1Hz를 샘플링레이트로 정규화하면 값이 극단적으로 작아져 극점이 단위원 밖으로 나간다.

| fs | 정규화 하한 | 극점 최대반경 | 상태 |
|---|---|---|---|
| 10Hz | 0.02000 | 0.982 | OK |
| **78Hz** | 0.00256 | **1.0039** | 불안정 |
| **126Hz** | 0.00159 | **1.0037** | 불안정 |

합성 0.25Hz 사인파 검증 (fs=126Hz):

| 방식 | 검출 피크 | 출력 범위 |
|---|---|---|
| `b, a` + `filtfilt` | **0.133Hz** (오답) | ±9×10³⁷ (발산) |
| `sos` + `sosfiltfilt` | **0.256Hz** (정답) | ±1.16 |

78Hz에서는 출력이 우연히 유한해 **그럴듯한 그래프가 나왔고**, 그래서 오래 발견되지 않았다.
→ `output="sos"` + `sosfiltfilt` 로 교체. 이 대역에서 `b, a` 형태는 절대 쓰면 안 된다.

### 발견 2 — 기준선 파일의 라벨이 틀렸음

`baseline_empty.pcap` 이 실제로는 **빈 방이 아니었다.** 사람이 있는 방을 노이즈 플로어로
놓고 비교했으니 기준 자체가 틀려 있었다. (현재 `baseline_occupied_20260713.pcap` 으로 개명)

→ 재발 방지로 [`data/README.md`](./data/README.md) 대장을 두고 캡처마다 실제 환경 조건을 기록한다.

### 수정 후 재분석

| 캡처 | 메트로놈 | 결과 |
|---|---|---|
| breath_12bpm | 12 | 0.287Hz = 17.2 BPM |
| breath_15bpm | 15 | 0.287Hz = 17.2 BPM |
| breath_20bpm | 20 | 0.271Hz = 16.3 BPM |

셋 다 16~17 BPM에 수렴하고, **검증된 빈 방 캡처에서는 이 성분이 나오지 않는다**
(선명도 2.51로 전체 최저 — 대역에 주기 성분 없음).

**유력 가설:** 시스템은 호흡을 잡고 있었으나 메트로놈 박자가 아니라
**피험자의 자연 호흡수(약 17회/분)** 를 잡았다. 다만 두 캡처의 길이·샘플링레이트가
달라 직접 비교가 성립하지 않으므로 **아직 확정할 수 없다.**

### 재실 여부에 따른 분리 (2026-08-25)

같은 22초·같은 서브캐리어 243개로 맞춘 세 기준선 (밴드 하한 0.15Hz):

| 방 상태 | 피크 분포 | 선명도 |
|---|---|---|
| **0명** | 217/243이 밴드 최하단 (대역에 성분 없음) | 2.50 |
| **6명** | 173/243이 **0.20Hz**, 38개가 0.30Hz | 3.82 |
| **1명** | 215/243이 **0.20Hz 한 점** | 3.76 |

사람이 있으면 0.15~0.30Hz(= 9~18회/분)에 에너지가 생기고 빈 방이면 생기지 않는다.
1명일 때는 한 점에 집중되고, 6명일 때는 여러 주파수로 갈린다.

**아직 호흡의 확증은 아니다** — ground truth 없이 관찰된 상관이고, 캡처마다 길이와
샘플링레이트가 달라 완전한 통제 비교가 아니다. 다만 재실 여부와 호흡 대역 에너지가
함께 움직인다는 점은 일관되게 재현된다.

### 밴드 하한: 0.1Hz 가 아니라 0.15Hz

**0.1Hz = 분당 6회**로, 성인 안정 호흡(12~20회)보다 느리다. 즉 0.1~0.15Hz 구간에는
호흡이 있을 수 없고 자세 변화 같은 느린 몸 움직임만 들어온다. 하한을 0.1로 두면
이 드리프트가 대역을 점령해 90초 캡처에서 서브캐리어 226/243이 밴드 최하단에 몰렸다.
0.15로 올리자 같은 캡처가 0.20Hz / 0.30Hz 로 갈렸고, **빈 방 대조군은 여전히 최하단에
남았다** — 이것이 파라미터 조작이 아님을 보증한다.

### 다음 실험

메트로놈을 먼저 시도한 것이 실책이었다 — "박자 추종"은 "감지 자체"보다 어려운 과제다.
순서를 뒤집어, 같은 세션·같은 설정으로 **90초씩 두 번**만 찍는다.

- **있음**: 사람이 앉아서 자연스럽게 호흡 (박자 맞추지 않음)
- **없음**: 방에서 나간 상태

있음에서만 0.25~0.30Hz 피크가 나오면 호흡 감지가 성립한다. 그 다음에 메트로놈으로 간다.

## 사용법

### 준비

```bash
pip install csikit numpy scipy matplotlib
cp config.example.sh config.sh    # SSID, MAC 등 실제 값 입력
```

환경 구축(OS 설치 ~ Nexmon 패치)은 [`nexmon_csi_setup.md`](./nexmon_csi_setup.md) 참조.
한 번만 하면 된다.

### 캡처

```bash
source config.sh
```

이후 절차는 [`RUN.md`](./RUN.md) 를 순서대로. 요약하면:
파이에 CSI 파라미터 주입 → 트래픽 발생기에서 ping 시작 → 배치 → 사전 점검 → 본 캡처.

> ⚠️ 캡처는 **패킷 수가 아니라 시간 기준**(`timeout 90`)으로. 샘플링레이트가
> 77~127Hz로 변동해서 `-c 6000` 으로 찍으면 캡처마다 길이가 달라진다.

### 분석

**먼저 진단한다.** `csi_pipeline.py` 는 신호가 없어도 BPM 숫자를 뱉기 때문에,
그 숫자부터 보면 잡음을 호흡으로 오독한다 (1차 실패가 정확히 이 함정).

```bash
python3 csi_diagnose.py data/breath_15bpm.pcap --expect 15
```

서브캐리어를 개별로 훑어 정답 주파수에 반응하는 비율을 본다.
밴드 0.1~0.6Hz에서 ±0.02Hz가 우연히 맞을 확률이 약 8%이므로, 이를 유의미하게 넘어야 신호가 있는 것이다.

```
[결과] 정답 0.250Hz(±0.02) 히트: 21/212 (10%)
       우연 수준 ≈ 8%
[판정] ⚠️  우연과 구별 안 됨 — 신호 있다고 말할 수 없음
```

✅ 판정이 나온 뒤에만 BPM을 추정한다:

```bash
python3 csi_pipeline.py data/breath_15bpm.pcap --plot out.png
```

## 알려진 한계

- **대상이 정지 상태여야 한다.** 걸어다니면 호흡 신호는 몸통 움직임에 완전히 묻힌다.
  실용적으로는 수면 중 / 앉은 자세 모니터링에 적합하다.
- **한 명만.** 다중 인원 호흡 분리에는 안테나 배열이 필요하다.
- **환경 의존성이 크다.** 가구 배치만 바꿔도 재보정이 필요하다.
- **다른 사람이 같은 방에 있으면 안 된다.** CSI는 반사 경로의 합이라
  직선 경로 밖의 움직임도 그대로 섞인다.
- ⚠️ **이 시스템을 유일한 안전망으로 쓰면 안 된다.** 응급벨 등과 병행할 것.
