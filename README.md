# wifisoloman

**저장소:** https://github.com/devsign2026/wifisoloman (organization `devsign2026`, public)

WiFi CSI(Channel State Information)로 **사람의 호흡을 비접촉 감지**하는 실험 프로젝트.

라즈베리파이의 WiFi 칩(BCM43455c0)을 [Nexmon CSI](https://github.com/seemoo-lab/nexmon_csi)로 패치해
전파의 미세한 변화를 뽑아내고, 신호처리로 분당 호흡수(BPM)를 추정한다.
카메라나 웨어러블 없이 **전파만으로** 재실·호흡을 감지하는 것이 목표.

> ⚠️ 진행 중인 실험이며, **아직 호흡 감지가 검증되지 않았다.** 아래 「현재 상태」 참조.

---

## 원리

WiFi 전파는 송신기에서 수신기까지 직선으로만 가지 않는다. 벽·가구·사람에 반사되어
수십 갈래 경로로 들어오고, CSI는 그 합을 서브캐리어(주파수 채널) 단위로 기록한 값이다.

사람이 숨을 쉬면 가슴이 수 mm 움직이고, 그만큼 반사 경로의 길이가 변한다.
이 변화가 CSI 진폭에 **호흡 주기(0.2~0.5Hz)의 미세한 진동**으로 나타난다.
즉 WiFi를 저해상도 레이더처럼 쓰는 셈이다.

```
[트래픽 발생기] ~~~전파~~~> [파이 = CSI 수신]
       └──── 사이에 사람 (호흡으로 반사 경로 변조) ────┘

[공유기] ← ping 목적지일 뿐. 측정 경로에 없음
```

CSI는 패킷이 날아갈 때만 추출되므로 ping으로 트래픽을 강제 유발한다.
`makecsiparams -m` 필터가 트래픽 발생기 MAC으로 걸려 있어, 측정되는 채널은
**트래픽 발생기 → 파이** 경로다. 공유기는 ping을 받아주는 역할만 한다.

## 구성

| 역할 | 장비 |
|---|---|
| CSI 수신 (센서) | Raspberry Pi 4B, 커널 `5.10.92-v7l+` 고정, Nexmon CSI 패치 |
| 신호원 | 5GHz 공유기, 채널 149 / 80MHz 고정 |
| 트래픽 발생기 | 여분 노트북 — `ping -i 0.02` 로 초당 50패킷 |
| 분석 | Python (CSIKit, numpy, scipy) |

80MHz 대역에서 서브캐리어 **256개**, 실측 샘플링레이트 **19~142Hz**
(ping 간격과 신호 세기에 따라 변동). 호흡(0.2~0.5Hz) 감지에는 어느 쪽이든 충분히 빠르다.

RSSI 는 배치에 매우 민감하다 — 맥북↔파이 간격을 1m 로 좁히자 -59dBm → **-43dBm** 로 개선됐다.
**측정 경로는 맥북→파이이므로 이 둘의 거리만 중요하고, 공유기 위치는 무관하다.**

## 신호처리 파이프라인

```
pcap 파싱 (CSIKit)
  → 진폭 추출 + 손상 프레임 제거
  → 유효 서브캐리어 선택 (null/가드밴드 제외)
  → 불균일 샘플링 보정 (선형보간 재샘플링)
  → 밴드패스 0.15~0.6Hz  ※ 반드시 SOS 형태
  → FFT → 피크 주파수 × 60 = BPM
```

재실/움직임 판정은 **진폭이 아니라 위상**을 쓴다 (`csi_presence.py`, `csi_live.py`).
진폭으로는 사람이 있는 방과 빈 방이 구분되지 않았다 (p=0.900).

## 현재 상태

**결론: 이 하드웨어로는 "움직임 이벤트"까지만 검출된다.**

2026-08-26 구석 세션에서 역대 최상 조건(RSSI **-43dBm**, 샘플링 **42Hz**, 맥북↔파이 **1m**,
완전한 빈 방)으로 재측정한 결과:

| 대상 | 결과 | 근거 |
|---|---|---|
| 몸 움직임 (걷기, 자세 변경) | ✅ 검출 | 전환 순간 2.040 vs 나머지 1.793, p=0.039 |
| 정지한 사람의 재실 | ❌ 불가 | 빈방 0.579 vs 착석 0.595, **겹침 6/6, p=0.26** |
| 이동 방향 (접근/이탈) | ❌ 불가 | 입실 2.048 vs 퇴실 1.992, p=0.468 |
| 호흡 (자연) | ❌ 불가 | 주파수 증거 없음, 선명도 전 구간 ~2 |
| 호흡 (**의도적 과장**) | ❌ 불가 | 0.25Hz 비중 8.6% vs 빈방 9.6%, **p=0.80** |

> ⚠️ **안전 용도로 쓰지 마십시오.** 호흡 정지 감지에 사용할 수 없습니다.
> 정지한 사람은 아예 검출되지 않으므로, 쓰러져 움직이지 않는 사람은 빈 방과 구별되지 않습니다.

### ⚠️ 이전 "재실 감지 성공" 주장은 정정되었다

2026-08-26 오전에 "재실 감지 성공 (겹침 0, p<0.0001, Cohen d=3.19)" 로 보고했으나,
그때의 "사람 있음" 캡처는 **4~6명이 자연스럽게 움직이던 상황**이었다.
같은 날 저녁 통제된 재측정에서 **가만히 앉은 한 사람은 빈 방과 구별되지 않았다.**

```
120s 0.905  ← 걸어 들어오는 중       ✅ 검출
150s 0.862  ← 자리 잡는 중           ✅ 검출
180s 0.621  ← 앉아서 정지
210s 0.566  ← 정지 (빈 방 0.579 와 동일)  ❌
```

즉 검출하고 있던 것은 **재실이 아니라 움직임**이었다.

### 대조군이 오독을 막은 사례

같은 세션에서 **빈 방** 스펙트럼에 0.333Hz(20 BPM) 피크가 히트율 **87%** 로 나타났다.
사람이 앉아 있을 때(44%)보다 오히려 "호흡처럼" 보인다. 선명도는 양쪽 다 2.2~2.5로 평평하다.

빈 방 대조군 없이 사람 데이터만 봤다면 "20 BPM 호흡 검출" 로 발표했을 것이다.
**이 프로젝트에서 가장 중요한 방법론적 교훈이다.**

### 마지막 반론까지 닫은 실험

"자연 호흡이 너무 약해서 안 잡힌 것 아니냐"에 답하기 위해, 최상 조건에서
**의도적으로 과장한 깊은 호흡**을 일정 리듬(2초 들이쉬고 2초 내쉬기 = 0.25Hz)으로 수행했다.

| | 0.25Hz 대역 에너지 비중 |
|---|---|
| 깊은 호흡 | 8.6% |
| **빈 방** | **9.6%** |
| | p=0.80 |

빈 방이 오히려 높다. 의도적으로 만든 0.25Hz 진동이 신호에 전혀 반영되지 않았다.
숨참기 구간도 깊은 호흡 구간보다 오히려 값이 높았다 (0.647 vs 0.617, p=0.74).

**더 좋은 조건을 만들 방법이 없다.** 과장된 호흡조차 검출되지 않으므로
이 하드웨어의 호흡 감지 불가는 확정이다.

### 향후 계획

트래픽 발생기를 **ESP32-C5**(ESP32 계열 중 유일한 5GHz 듀얼밴드)로 교체할 예정이다.
맥북을 빼고 실험을 간소화하는 것이 목적이며, **호흡 감지 한계는 이걸로 해결되지 않는다**
— 교체 대상이 송신기이지 수신기가 아니기 때문이다.
상세는 [HARDWARE_PLAN.md](./HARDWARE_PLAN.md) 참조.

### 근본 원인 — 수신 안테나 1개

Pi 4B의 BCM43455c0은 **1x1** 이다 (CSI shape `(256, 1, 1)`, core 0 하나만 관측).

참고한 연구들의 핵심 기법이 전부 다중 안테나를 요구한다 — FarSense는 두 안테나의
CSI **비율**로, PhaseBeat는 안테나 **간 위상차**로 공통 위상 오차를 제거한다.
호흡 신호가 워낙 미약해 그 처리 없이는 드러나지 않는다. 소프트웨어로 우회할 수
있는 종류의 제약이 아니다.

## 개발 과정에서 잡은 버그들

### 발견 1 — 밴드패스 필터가 수치적으로 붕괴해 있었음 🚨

전달함수 계수(`b, a`) 형태로 만든 Butterworth 밴드패스가 **불안정**했다.
0.1Hz를 샘플링레이트로 정규화하면 값이 극단적으로 작아져 극점이 단위원 밖으로 나간다.

| fs | 정규화 하한 | 극점 최대반경 | 상태 |
|---|---|---|---|
| 10Hz | 0.02000 | 0.982 | OK |
| **78Hz** | 0.00256 | **1.0039** | 불안정 |
| **126Hz** | 0.00159 | **1.0037** | 불안정 |

합성 0.25Hz 사인파 검증 (fs=126Hz):

| 방식 | 검출 피크 | 출력 범위 |
|---|---|---|
| `b, a` + `filtfilt` | **0.133Hz** (오답) | ±9×10³⁷ (발산) |
| `sos` + `sosfiltfilt` | **0.256Hz** (정답) | ±1.16 |

78Hz에서는 출력이 우연히 유한해 **그럴듯한 그래프가 나왔고**, 그래서 오래 발견되지 않았다.
→ `output="sos"` + `sosfiltfilt` 로 교체. 이 대역에서 `b, a` 형태는 절대 쓰면 안 된다.

### 발견 2 — 기준선 파일의 라벨이 틀렸음

`baseline_empty.pcap` 이 실제로는 **빈 방이 아니었다.** 사람이 있는 방을 노이즈 플로어로
놓고 비교했으니 기준 자체가 틀려 있었다. (현재 `baseline_occupied_20260713.pcap` 으로 개명)

→ 재발 방지로 [`data/README.md`](./data/README.md) 대장을 두고 캡처마다 실제 환경 조건을 기록한다.

### 수정 후 재분석

| 캡처 | 메트로놈 | 결과 |
|---|---|---|
| breath_12bpm | 12 | 0.287Hz = 17.2 BPM |
| breath_15bpm | 15 | 0.287Hz = 17.2 BPM |
| breath_20bpm | 20 | 0.271Hz = 16.3 BPM |

셋 다 16~17 BPM에 수렴하고, **검증된 빈 방 캡처에서는 이 성분이 나오지 않는다**
(선명도 2.51로 전체 최저 — 대역에 주기 성분 없음).

**유력 가설:** 시스템은 호흡을 잡고 있었으나 메트로놈 박자가 아니라
**피험자의 자연 호흡수(약 17회/분)** 를 잡았다. 다만 두 캡처의 길이·샘플링레이트가
달라 직접 비교가 성립하지 않으므로 **아직 확정할 수 없다.**

### 재실 여부 분리 — 확인 실패 (2026-08-26)

한때 "사람이 있으면 호흡 대역(0.15~0.30Hz)에 에너지가 생기고 빈 방이면 생기지 않는다"고
정리했으나, **제대로 된 빈 방 기준선을 확보하자 무너졌다.**

당시 근거는 **22초짜리** 빈 방 캡처였다. 7분 빈 방 캡처를 찍고 길이를 39초로 맞춰
다시 비교하면 셋이 구분되지 않는다:

| 방 상태 | 우세 피크 | 선명도 |
|---|---|---|
| 0명 | 0.20Hz 152/244 | 2.09 |
| 6명 | 0.20Hz 128/243 | 2.22 |
| 1명 | 0.20Hz 172/242 | 2.99 |

**빈 방에서도 똑같이 0.20Hz가 나온다.** 결정적인 것은 빈 방 7분을 39초 창으로 쪼갠 결과로,
0.20Hz 우세 서브캐리어 수가 구간에 따라 **115 → 112 → 0 → 74 → 12 → 2 → 60** 으로 요동친다.
같은 빈 방인데 어디서 자르느냐에 따라 "강한 0.20Hz"와 "아무것도 없음"이 모두 나온다.

원인은 **선명도가 내내 2 수준**이라는 것이다. 스펙트럼이 평평하면 "피크 위치"는
잡음이 FFT 격자 위 어디에 앉았느냐일 뿐이다. 길이가 다른 캡처를 비교하면서
그 잡음의 위치 변화를 신호로 읽은 것이 오류였다.

→ 재발 방지로 `csi_diagnose.py` 에 **선명도 게이트**를 넣었다. 선명도가 4 미만이면
피크 분포를 출력하되 "해석하지 말 것"을 명시하고 판정을 거부한다.

**현재까지 이 프로젝트는 재실도 호흡도 검출하지 못했다.**

### 밴드 하한: 0.1Hz 가 아니라 0.15Hz

**0.1Hz = 분당 6회**로, 성인 안정 호흡(12~20회)보다 느리다. 즉 0.1~0.15Hz 구간에는
호흡이 있을 수 없고 자세 변화 같은 느린 몸 움직임만 들어온다. 하한을 0.1로 두면
이 드리프트가 대역을 점령해 90초 캡처에서 서브캐리어 226/243이 밴드 최하단에 몰렸다.
0.15로 올리자 같은 캡처가 0.20Hz / 0.30Hz 로 갈렸고, **빈 방 대조군은 여전히 최하단에
남았다** — 이것이 파라미터 조작이 아님을 보증한다.

### 다음 실험

메트로놈을 먼저 시도한 것이 실책이었다 — "박자 추종"은 "감지 자체"보다 어려운 과제다.
순서를 뒤집어, 같은 세션·같은 설정으로 **90초씩 두 번**만 찍는다.

- **있음**: 사람이 앉아서 자연스럽게 호흡 (박자 맞추지 않음)

있음에서만 0.25~0.30Hz 피크가 나오면 호흡 감지가 성립한다. 그 다음에 메트로놈으로 간다.

## 사용법

### 준비

```bash
pip install csikit numpy scipy matplotlib
cp config.example.sh config.sh    # SSID, MAC 등 실제 값 입력
```

환경 구축(OS 설치 ~ Nexmon 패치)은 [`nexmon_csi_setup.md`](./nexmon_csi_setup.md) 참조.
한 번만 하면 된다.

### 캡처

```bash
source config.sh
```

이후 절차는 [`RUN.md`](./RUN.md) 를 순서대로. 요약하면:
파이에 CSI 파라미터 주입 → 트래픽 발생기에서 ping 시작 → 배치 → 사전 점검 → 본 캡처.

> ⚠️ 캡처는 **패킷 수가 아니라 시간 기준**(`timeout 90`)으로. 샘플링레이트가
> 77~127Hz로 변동해서 `-c 6000` 으로 찍으면 캡처마다 길이가 달라진다.

### 분석

**먼저 진단한다.** `csi_pipeline.py` 는 신호가 없어도 BPM 숫자를 뱉기 때문에,
그 숫자부터 보면 잡음을 호흡으로 오독한다 (1차 실패가 정확히 이 함정).

```bash
python3 csi_diagnose.py data/breath_15bpm.pcap --expect 15
```

서브캐리어를 개별로 훑어 정답 주파수에 반응하는 비율을 본다.
밴드 0.1~0.6Hz에서 ±0.02Hz가 우연히 맞을 확률이 약 8%이므로, 이를 유의미하게 넘어야 신호가 있는 것이다.

```
[결과] 정답 0.250Hz(±0.02) 히트: 21/212 (10%)
       우연 수준 ≈ 8%
[판정] ⚠️  우연과 구별 안 됨 — 신호 있다고 말할 수 없음
```

✅ 판정이 나온 뒤에만 BPM을 추정한다:

```bash
python3 csi_pipeline.py data/breath_15bpm.pcap --plot out.png
```

> ⚠️ **`config.sh` 는 절대 커밋하지 말 것.** SSID·MAC·호스트명 같은 실제 값이 들어 있고
> `.gitignore` 로 막혀 있다. `git status` 에 뜨면 `.gitignore` 가 깨진 것이니 확인할 것.
>
> ⚠️ 이 저장소는 **public** 이다. 커밋 전에 새로 추가한 파일에 실제 SSID/MAC/비밀번호가
> 섞이지 않았는지 확인할 것:
> ```bash
> git grep -nIiE "실제SSID|실제MAC" -- '*.md' '*.py' '*.sh'
> ```

## 알려진 한계

- **대상이 정지 상태여야 한다.** 걸어다니면 호흡 신호는 몸통 움직임에 완전히 묻힌다.
  실용적으로는 수면 중 / 앉은 자세 모니터링에 적합하다.
- **한 명만.** 다중 인원 호흡 분리에는 안테나 배열이 필요하다.
- **환경 의존성이 크다.** 가구 배치만 바꿔도 재보정이 필요하다.
- **다른 사람이 같은 방에 있으면 안 된다.** CSI는 반사 경로의 합이라
  직선 경로 밖의 움직임도 그대로 섞인다.
- ⚠️ **이 시스템을 유일한 안전망으로 쓰면 안 된다.** 응급벨 등과 병행할 것.
