# 모바일 앱 GUI 디자인

WiFi CSI 센싱 앱의 화면 디자인. iOS HIG 다크 테마, 한국어 UI.

**캔버스:** https://claude.ai/code/artifact/564153fe-1b26-487f-988a-822667059362

---

## 화면 구성

| 파일 | 화면 | 설명 |
|---|---|---|
| `MonitorOff.dc.html` | 모니터 · 모드 꺼짐 | 외출 모드 시작 전 상태 |
| `Main.dc.html` | 모니터 · 감시 중 | 상태 카드 · 위상 파형 · 대역 에너지 추이 |
| `Events.dc.html` | 기록 | 외출 세션별 로그. **모드와 무관하게 항상 접근 가능** |
| `Device.dc.html` | 장비 | 연결 상태 · RSSI · 샘플링레이트 · 채널 |
| `Settings.dc.html` | 설정 | 임계값 · 기준선 재측정 · 알림 |
| `canvas.json` | — | 캔버스 배치 |

## 동작 모델

**외출 모드**를 켜야 감시가 시작된다. 모드를 켜면 실내가 비어 있다고 전제하고,
그 뒤 감지되는 움직임을 이상으로 기록한다.

```
모드 꺼짐  ──[외출 모드 시작]──▶  감시 중  ──[움직임]──▶  기록에 남김
                                    └──[종료]──▶  모드 꺼짐
```

## 실측값 반영

화면에 표시된 수치는 2026-08-26 구석 세션의 실측값이다.

- RSSI **-43 dBm** · 샘플링 **42.3 Hz** · 채널 **149 / 80 MHz** · 서브캐리어 **244 / 256**
- 빈 방 기준선 **0.579** (범위 0.471~0.721)

기록 탭의 세션 시각과 에너지값은 예시다.
